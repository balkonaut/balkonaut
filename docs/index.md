# Balkonaut

Balkonaut wertet die Messdaten eines Balkonkraftwerks mit Speicher aus und beantwortet
die Fragen, die das Energy-Dashboard von Home Assistant offen lässt: Wie viel spare ich?
Wann hat sich die Anlage bezahlt gemacht? Lohnt sich ein weiterer Akku?

!!! note "In Entwicklung"
    Balkonaut befindet sich im Aufbau. Dieses Handbuch wächst mit jeder Funktion mit.

## Balkonaut unterstützen

Balkonaut ist kostenlos und quelloffen. Wer die Entwicklung unterstützen möchte, kann auf
[buymeacoffee.com/balkonaut](https://buymeacoffee.com/balkonaut) einen Kaffee spendieren. Genauso hilfreich sind
Rückmeldungen zu Geräten, siehe [Gerät melden](integration.md#gerat-melden).
