# BalkonBilanz

BalkonBilanz wertet die Messdaten eines Balkonkraftwerks mit Speicher aus und beantwortet
die Fragen, die das Energy-Dashboard von Home Assistant offen lässt: Wie viel spare ich?
Wann hat sich die Anlage bezahlt gemacht? Lohnt sich ein weiterer Akku?

!!! note "In Entwicklung"
    BalkonBilanz befindet sich im Aufbau. Dieses Handbuch wächst mit jeder Funktion mit.
